## Обо мне
Работаю с цифровыми продуктами и проектами: от выявления потребностей бизнеса и сбора требований до проектирования решения и подготовки документации для разработки. Умею работать со стейкхолдерами, анализировать бизнес-процессы, выявлять проблемные места и переводить задачи бизнеса в технические требования. В работе использую BPMN, UML подходы к моделированию, ER диаграммы, User Stories, Use Cases, проектирую реляционные модели данных и пишу SQL запросы.  
  
Предыдущий опыт управления проектами помогает мне увидеть задачу не только с технической стороны, но и через пользовательский опыт и цели бизнеса.
